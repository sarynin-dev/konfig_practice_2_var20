# Визуализатор графа зависимостей (Maven / Java)

Инструмент визуализации графа зависимостей для пакетов Java (Maven)
с поддержкой работы с реальным репозиторием Maven Central и тестовым
репозиторием с абстрактными графами.
Выполнено по дисциплине «Конфигурационное управление», вариант №20.

## Требования к среде
- Python 3.10+
- Terrastruct D2 (опционально, встроен автоматический рендеринг)

## Структура проекта
- `src/` — исходный код приложения.
- `tests/` — модульные тесты и проверки стиля кода.
- `run.bat`, `run.sh` — скрипты запуска CLI приложения.
- `README.md` — документация к проекту.

## Параметры командной строки
- `--package`, `-p` (обязательный) — координаты Maven пакета
  (`groupId:artifactId[:version]`) или имя пакета в тестовом режиме.
- `--repo`, `-r` — URL-адрес репозитория или путь к файлу графа
  (по умолчанию `https://repo1.maven.org/maven2`).
- `--test-mode`, `-t` — включение режима работы с тестовым репозиторием.
- `--output`, `-o` — имя сгенерированного файла с изображением графа
  (по умолчанию `graph.png`).
- `--ascii-tree`, `-a` — вывод дерева зависимостей в формате ASCII.

## Сборка и запуск тестов
Запуск модульных тестов:
```bash
python -m unittest discover tests
```

## Примеры использования
### Этап 1. Минимальный прототип с конфигурацией
Вывод параметров командной строки в формате ключ-значение.

### Этап 2. Сбор данных о зависимостях Maven
Извлечение прямых зависимостей заданного пакета из репозитория без
использования сторонних библиотек и пакетных менеджеров:
```bash
run.bat --package com.google.guava:guava:31.1-jre
```

### Этап 3. Основные операции и тестовый режим
Построение графа зависимостей с помощью итеративного алгоритма DFS
(без рекурсии), обработка циклических зависимостей и работа с тестовым
репозиторием (пакеты из заглавных латинских букв):
```bash
run.bat --test-mode --repo tests/data/cycle.txt --package A
```
